# 🏸 バド乱数表(simple_badminton)

バドミントンのダブルスを、公平に楽しむためのアプリです。出場回数の均等化・休憩の管理・男女ミックス優先・腕前の均等化を自動で行い、勝敗の記録から本日の MVP を表彰します。試合中に使える得点板も付いています。スマホのホーム画面に追加すると、体育館が圏外でも使えます(PWA)。

**公開 URL**: https://mmishina-art.github.io/simple_badminton/

## 機能

- **メンバー**: 1人ずつ/まとめて登録、サンプル8名、参加・お休みの切り替え、性別・腕前のワンタップ変更
- **試合**: コート数(1〜4面)に合わせて、出場回数の均等化・男女ミックス優先・腕前の均等化で組み合わせを自動作成。勝敗はタップで記録。再シャッフル、音声での組み合わせ発表
- **成績**: MVP・準MVP・敢闘賞、成績表、試合履歴、LINE に貼れる結果テキスト
- **得点板**: 11/15/21 点先取、デュースあり・なし、マッチポイント表示、1手戻す、サーブ権、チェンジエンド、巨大全画面、画面の常時点灯、バイブ、試合との連動
- **設定**: QR コード、メンバーのテキスト保存・復元、記録のバックアップ(ファイル)、データのリセット
- 完全オフライン対応(PWA)。記録は端末の中だけに保存します

## 以前のアプリ(v2.5)からの引き継ぎ

以前のアプリの「メンバーの保存」テキスト(`名前 男 初級` の行)は、「メンバー」タブの「まとめて登録」か、「設定」のメンバーの復元に貼り付けて取り込めます。履歴は引き継げません。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## 素材とライセンス

画像(アイコン)は、このリポジトリのコード(`scripts/make-icons.mjs`)で描いています。音声は、端末の音声合成(Web Speech API)を使い、音声ファイルは持ちません。外部のサービス・ネットからの読み込みはありません。
